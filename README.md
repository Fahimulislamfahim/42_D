# forty_two_d

A Flutter mobile application named "42_D" for classroom management with an agentic AI architecture.

## Getting Started

### NVIDIA NIM Integration
This project uses the NVIDIA API for AI agent interactions. You must set up an environment file before running the application.

1. Create a file named `.env` in the root of the project.
2. Add your NVIDIA API key to the file in the following format:
   ```env
   NVIDIA_API_KEY=your_actual_api_key_here
   ```
